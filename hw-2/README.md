# CyberZoo Dashboard

Виртуальное приложение для управления цифровым зоопарком, где пользователи взаимодействуют с цифровыми питомцами.

## Возможности

### Основной функционал

- Управление несколькими питомцами
- У каждого питомца есть параметры: энергия, настроение, уровень
- Действия над питомцем: покормить, повысить уровень, подбодрить, сбросить
- Автоматическое падение энергии по таймеру
- Система настроения: меняется в зависимости от энергии (happy / neutral / sad)
- Журнал событий: глобальный лог всех действий с временем
- Фильтрация по виду питомца (через Material UI Select)
- Скелетон-загрузка при получении данных

### Логика кнопки Cheer

- Действие Cheer:
  - Делает настроение питомца happy
  - Дает небольшой бонус к энергии
  - Включает временную защиту настроения
- Защита настроения:
  - В течение ограниченного времени после Cheer настроение не может ухудшиться
  - Падение настроения, вызванное низкой энергией или логикой жизненного цикла, блокируется, если оно делает состояние хуже текущего
  - По окончании таймера защита автоматически снимается
- Таким образом Cheer дает пользу: временно стабилизирует питомца и не позволяет сразу скатиться обратно в плохое настроение при низкой энергии

## Техническая реализация

### Использование React-хуков

- `useState` и `useEffect`: загрузка данных о питомцах, состояние фильтра, таймеры
- `useReducer`: управление состоянием питомца в `PetCard` (энергия, настроение, уровень, Cheer и др.)
- `useRef`: работа с DOM для эффектов аватара
- `useMemo`: мемоизация списка отфильтрованных питомцев и списка видов
- `useCallback`: мемоизированные обработчики действий
- `React.memo`: оптимизация `PetCard`
- `useContext`: глобальный контекст для журнала событий
- Кастомные хуки:
  - `usePetLifecycle`: таймер снижения энергии и изменение настроения
  - `useEventLog`: работа с контекстом событий

### Подходы к стилизации

Все требуемые методы стилизации используются хотя бы один раз:

1. **SCSS (global.scss)** — общий лайаут, сетка, адаптивность
2. **CSS Modules (PetCard.module.scss)** — стили карточки питомца
3. **Inline styles** — динамическая тень карточки в зависимости от настроения
4. **styled-components** — кнопки действий `ActionButton` и `ResetButton`
5. **Material UI** — Drawer, Select, Skeleton, Paper, List и другие компоненты

## Действия с питомцами

- **Feed (Покормить)**: увеличивает энергию питомца на 20 (максимум 100)
- **Level Up (Апгрейднуть)**: повышает уровень на 1
- **Cheer (Порадовать)**:
  - Ставит настроение в состояние happy
  - Дает небольшой бонус энергии
  - Включает временную защиту от ухудшения настроения
- **Reset (Сбросить)**: возвращает питомца в исходное состояние
- **Автотаймер энергии**: энергия уменьшается через заданные интервалы времени

## Состояния питомца

### Уровни энергии (примерная логика)

- 100–51: настроение happy
- 50–21: настроение neutral
- 20–1: настроение sad
- 0: питомец недоступен для действий

### Цвета настроения

- Happy: зеленое свечение
- Neutral: желтое свечение
- Sad: красное свечение
